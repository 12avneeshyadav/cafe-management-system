☕ Cafe Management System
A simple command-line based Cafe Management System built in Python. This project helps manage cafe orders interactively through the terminal.

📋 Features

📜 View full cafe menu with prices
🛒 Place orders for multiple items with quantity
🧾 Generate itemized bill with total amount
✅ Input validation and error handling


🍽️ Menu Categories
CategoryItems🍔 Fast FoodBurger, Cheese Burger, Veg Sandwich, Grilled Sandwich, French Fries, Peri Peri Fries, Pizza🥪 SnacksSamosa, Kachori, Patties, Garlic Bread, Nachos☕ BeveragesTea, Green Tea, Black Coffee, Cold Coffee, Cappuccino, Latte

🚀 How to Run
Prerequisites

Python 3.x installed on your system

Steps
bash# 1. Clone the repository
git clone https://github.com/codebyavneesh/cafe-management-system.git

# 2. Navigate to the project folder
cd cafe-management-system

# 3. Run the program
python cafe_management.py

🖥️ Usage
-------------- Cafe Management Menu ----------------
1. Show Menu
2. Order Item
3. Show Bill
4. Exit

Enter 1 → View all menu items with prices
Enter 2 → Place an order (enter item name + quantity)
Enter 3 → View your bill
Enter 4 → Exit the program
